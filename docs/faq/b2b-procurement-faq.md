## 2. Sample Submission

### How should I send samples from multiple birds?
Each bird must be sampled separately. Recommended packaging:
1. Each bird's feathers in a **separate paper envelope**
2. Envelopes grouped in a **single padded mailer**
3. Submission form **outside** the envelopes (to prevent contamination)
4. Label each envelope with the bird's ID

### What information must accompany each sample?

| Required Field | Example |
|:---------------|:--------|
| Bird ID / Name | AG-047 |
| Species | African Grey Parrot |
| Test Required | DNA Sexing |
| Sample Type | Feather |
| Collection Date | 2026-04-15 |

### Can I pool samples to save cost?
Pooling (mixing samples from multiple birds) is not recommended for sexing — mixed DNA produces ambiguous results. For disease screening, **pooled testing (3–5 birds per pool)** is available as a cost-saving surveillance option.

### Do you accept international samples?
Yes. SENO processes samples from 20+ countries. We provide full customs documentation support including commercial invoices and customs letters. Shipping guidance is available upon request.

## 4. Quality & Guarantees

### What accuracy rate do you guarantee?
SENO guarantees ≥ 99% accuracy for DNA sexing tests based on our internal validation. Discrepant results are investigated at no charge.

### What if I disagree with a result?
SENO offers free retesting on any result the client disputes:
1. Notify us within 30 days of report
2. Provide a fresh sample (if sample condition is in question)
3. Free retest with alternate primer set
4. If discrepancy is confirmed: full refund + free retest of remaining batch

### Do you offer refunds?
| Scenario | Refund Policy |
|:---------|:--------------|
| Lab error (confirmed) | Full refund + free retest |
| Sample quality failure | Free retest with fresh sample |
| Client cancels before processing | 100% refund |
| Result is unexpected but accurate | No refund (confirmed by QC review) |
