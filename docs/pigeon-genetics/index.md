# Racing Pigeon Genetics


Advanced genetic analysis for racing pigeon breeding, performance optimization, and pedigree verification. SENO's genetics division, based in Zhangjiakou, China, develops and validates molecular markers specifically for racing pigeon (*Columba livia domestica*) populations. Our testing panel covers four established performance-associated genes plus high-resolution DNA fingerprinting and parentage verification systems.

## Why Genetic Testing for Racing Pigeons?

Genetic testing provides pigeon fanciers and breeders with objective data to inform breeding decisions. By understanding the genetic makeup of individual birds, breeders can:

| Benefit | Description | Impact on Performance |
|:--------|:------------|:---------------------|
| Identify performance potential | DRD4, LDHA, CK, and MB markers correlate with racing traits | 5–15% improvement in race outcome prediction |
| Verify parentage | DNA-based confirmation of pedigree records | Prevents fraud in high-value bird trade |
| Prevent theft | Permanent genetic identity for each bird | Definitive ownership proof |
| Manage genetic diversity | Inbreeding coefficient calculations | Reduces loss of heterozygosity |
| Optimize pairings | Marker-assisted selection for complementary traits | More consistent offspring quality |
| Document breeding lines | Long-term genetic record keeping | Traceable lineage across generations |

## Performance Gene Panel Overview

### DRD4 (Dopamine Receptor D4)

| Attribute | Detail |
|:----------|:--------|
| Full Name | Dopamine Receptor D4 |
| Function | Neurotransmission regulation; linked to novelty-seeking, motivation, and activity levels |
| Polymorphism | 14-bp indel in exon 3 (VNTR) |
| Associated Phenotype | Higher activity levels, endurance, racing motivation |
| Allele Designation | Long (L) / Short (S) — LL genotype associated with better long-distance performance |
| Validation Source | SENO internal study (n = 120 racing pigeons, 2024) |
| Heritability Estimate | Moderate (0.35–0.45) |

### LDHA (Lactate Dehydrogenase A)

| Attribute | Detail |
|:----------|:--------|
| Full Name | Lactate Dehydrogenase A |
| Function | Anaerobic glycolysis; converts pyruvate to lactate; muscle energy metabolism |
| Polymorphism | SNP in promoter region (c.-97T>C) |
| Associated Phenotype | Lactate clearance rate, muscle endurance |
| CC Genotype | Higher LDHA expression, faster lactate clearance, better sprint performance |
| TT Genotype | Lower LDHA expression, slower lactate clearance, reduced sprint capacity |
| Validation Source | SENO internal study (n = 120 racing pigeons, 2024) |
| Heritability Estimate | Moderate (0.30–0.40) |

### CK (Creatine Kinase)

| Attribute | Detail |
|:----------|:--------|
| Full Name | Creatine Kinase — Muscle-type |
| Function | ATP regeneration in muscle cells; phosphocreatine energy shuttle |
| Polymorphism | Intronic SNP (g.IVS2-46A>G) |
| Associated Phenotype | Muscle energy metabolism, recovery rate after exertion |
| GG Genotype | Higher CK activity, faster ATP regeneration, improved recovery |
| AA Genotype | Lower CK activity, slower recovery |
| Validation Source | SENO internal study (n = 120 racing pigeons, 2024) |
| Heritability Estimate | Moderate (0.30–0.42) |

### MB (Myoglobin)

| Attribute | Detail |
|:----------|:--------|
| Full Name | Myoglobin |
| Function | Oxygen storage and transport in cardiac and skeletal muscle |
| Polymorphism | SNP in coding region (c.47A>G; Lys15Arg) |
| Associated Phenotype | Aerobic endurance, oxygen buffering capacity |
| GG Genotype | Higher myoglobin affinity or expression; better endurance performance |
| AA Genotype | Lower oxygen buffering; better in shorter distances |
| Validation Source | SENO internal study (n = 120 racing pigeons, 2024) |
| Heritability Estimate | Moderate (0.28–0.38) |

## Sample Collection Instructions

### Feathers

| Step | Instruction |
|:-----|:------------|
| 1 | Select 5–7 chest or wing feathers |
| 2 | Pluck firmly (do not cut) to include the calamus (quill base) |
| 3 | Place in a clean paper envelope |
| 4 | Label envelope with bird's ring number and date |
| 5 | Store at room temperature — stable for years |

### Blood (FTA Card)

| Step | Instruction |
|:-----|:------------|
| 1 | Use a sterile lancet to prick the medial metatarsal vein |
| 2 | Touch the blood drop to the FTA card circle (fill completely) |
| 3 | Allow to air dry for 1 hour |
| 4 | Label card with bird's ring number and date |
| 5 | Store in a sealed plastic bag at room temperature |
