# Disease Testing Index


SENO offers comprehensive molecular diagnostics for avian pathogens using validated qPCR and conventional PCR methods. Each assay includes internal amplification controls and is validated against clinical samples. All testing is performed at our ISO-accredited laboratory in Zhangjiakou, China, with a typical turnaround of 1–5 working days depending on the test panel.

## Detailed Test Specifications

### PBFD Detection (qPCR)

| Parameter | Value |
|:----------|:-------|
| Target Gene | Rep (replication-associated protein) |
| Assay Format | TaqMan probe-based qPCR |
| Limit of Detection | 50 copies/reaction |
| Specificity | 100% against 12 related circoviruses |
| Recommended for | Psittacine birds, sick or pre-purchase screening |

### Avian Polyomavirus (Conventional PCR)

| Parameter | Value |
|:----------|:-------|
| Target Gene | VP1 (major capsid protein) |
| Assay Format | Conventional PCR with nested options |
| Limit of Detection | ~100 copies/reaction |
| Recommended for | Young psittacines, especially budgerigars and lovebirds |

### Pigeon Disease Panel (Multiplex qPCR)

| Parameter | Value |
|:----------|:-------|
| Number of Targets | 11 (pathogens + internal control) |
| Assay Format | Multiplex qPCR (4-plex × 3 reactions + IC) |
| Sample Types | Oral swab, cloacal swab, combined swab |
| Recommended for | Pre-race screening, new bird quarantine, outbreak investigation |

### Avian Influenza Surveillance (RT-PCR)

| Parameter | Value |
|:----------|:-------|
| Screening Target | Influenza A matrix (M) gene |
| Subtyping | H5, H7, and H9-specific RT-PCR |
| Pooled Testing | Up to 3 birds per pool for surveillance |
| Recommended for | Racing pigeons during active season, permit requirements, outbreak monitoring |

## How to Choose a Disease Test

| Clinical Scenario | Recommended Test | Sample Type | Turnaround |
|:------------------|:-----------------|:------------|:-----------|
| Feather loss, beak deformity in parrot | PBFD qPCR | 3–5 chest feathers | 1–2 working days |
| Sudden death in young budgerigar | APV PCR | Cloacal swab or tissue | 2–3 working days |
| Respiratory signs in racing pigeon flock | Pigeon Disease Panel | Oral + cloacal swab | 2–3 working days |
| Pre-race screening (permit requirement) | AIV RT-PCR (H5/H7/H9) | Oral swab | 2–3 working days |
| Multi-symptom investigation | Panel + targeted qPCR | As indicated | 3–5 working days |
| Import/export certification | Full screening panel | Per destination requirements | 5 working days |

## Sampling and Submission Guidelines

### Sample Collection

| Matrix | Collection Method | Minimum Volume / Quantity | Storage (Short-term) | Storage (Long-term) |
|:-------|:------------------|:--------------------------|:---------------------|:---------------------|
| Feathers | Pluck (do not cut) from chest | 3–5 calamus-intact feathers | Room temp in paper envelope | Room temp, dry |
| Cloacal swab | Sterile flocked swab | Tip fully coated | 2–8 °C, dry tube | −20 °C |
| Oral swab | Sterile flocked swab | Tip fully coated | 2–8 °C, dry tube | −20 °C |
| Blood | FTA card or EDTA tube | 1 spot (FTA) or 0.5 mL (EDTA) | Room temp (FTA); 2–8 °C (EDTA) | Room temp (FTA) |
| Tissue | Sterile container with PBS | 5 × 5 × 5 mm piece | 2–8 °C (refrigerate) | −20 °C or −80 °C |

### Packaging and Shipping

| Requirement | Instruction |
|:------------|:------------|
| Primary container | Leak-proof tube or bag with absorbent material |
| Secondary container | Sealed plastic bag or biohazard pouch |
| Outer packaging | Rigid box or padded envelope with biohazard label (if applicable) |
| Cold chain (swabs/tissue) | Ice packs inside insulated box |
| Documentation | Completed submission form + sample manifest |
| Courier | SF Express or equivalent; mark "Biological Substance, Category B" (UN3373) |
