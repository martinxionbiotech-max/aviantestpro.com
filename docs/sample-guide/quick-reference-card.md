# Sample Collection Quick-Reference Card

## Feather Collection (DNA Sexing)

```
┌─────────────────────────────────────────────┐
│           FEATHER COLLECTION                 │
├─────────────────────────────────────────────┤
│  ☑ Use freshly plucked feathers ONLY        │
│  ☑ 3–5 feathers per bird                    │
│  ☑ Small birds: 5–7 feathers                │
│  ☑ Pluck from chest or flank                │
│  ☑ Check: follicle bulb visible at base     │
│  ☑ Store in paper envelope (NOT plastic)    │
│  ☑ Label each envelope with bird ID         │
│  ☑ Room temperature storage                 │
│  ☑ Ship within 4 weeks of collection        │
└─────────────────────────────────────────────┘
```

## Swab Collection (Disease Testing)

```
┌─────────────────────────────────────────────┐
│           SWAB COLLECTION                    │
├─────────────────────────────────────────────┤
│  ORAL SWAB:                                  │
│  ☑ Insert into oropharynx + choanal slit    │
│  ☑ Rotate 5–10 seconds                      │
│  ☑ Place into stabilization solution        │
│                                              │
│  CLOACAL SWAB:                               │
│  ☑ Insert 0.5–1 cm into cloaca              │
│  ☑ Rotate 3–5 seconds                       │
│  ☑ Place into stabilization solution        │
│                                              │
│  ☑ Seal tube tightly                        │
│  ☑ Label with bird ID + date                │
│  ☑ Store at 2–8°C → ship with cold pack     │
└─────────────────────────────────────────────┘
```

## Blood Collection (FTA Card / Filter Paper)

```
┌─────────────────────────────────────────────┐
│           BLOOD COLLECTION                   │
├─────────────────────────────────────────────┤
│  FTA CARD:                                   │
│  ☑ Apply 1–2 drops blood to card            │
│  ☑ Allow to air-dry 30 min (no direct sun)  │
│  ☑ Store in sealed bag with desiccant       │
│  ☑ Room temperature storage (years)         │
│                                              │
│  FILTER PAPER (DBS):                         │
│  ☑ Apply 3–4 drops blood to card            │
│  ☑ Air-dry completely (> 1 h)               │
│  ☑ Store individually in paper envelopes    │
│  ☑ Room temperature or refrigerated         │
└─────────────────────────────────────────────┘
```

## Specimen Stability

| Sample Type | Room Temp (20–25°C) | Refrigerated (2–8°C) | Frozen (–20°C) |
|:------------|:-------------------:|:--------------------:|:--------------:|
| Feather (dry) | 4 weeks | 6 months | Indefinite |
| Blood (FTA card) | Indefinite | Indefinite | Indefinite |
| Blood (EDTA tube) | 24 h | 7 days | — |
| Swab (dry) | 24 h | 3 days | — |
| Swab (stabilization buffer) | 7 days | 4 weeks | 6 months |
| Tissue (in RNA later) | 1 week | 4 weeks | Indefinite |

## Common Errors & Prevention

| Error | Consequence | Prevention |
|:------|:------------|:-----------|
| Using molted feathers | No DNA (no follicle) | Always pluck fresh feathers |
| Plastic bag for feathers | Condensation → mold → DNA degradation | Always use paper envelope |
| Missing bird ID on sample | Sample cannot be processed | Label each envelope before collection |
| Swab tube leakage | Biohazard risk + sample loss | Double-check cap seal; use secondary container |
| Storage in direct sunlight | UV damage → DNA degradation | Store in opaque container or dark location |
| Over-drying blood spot | DNA may fragment | Follow drying time: 30–60 min, not > 2 h |
