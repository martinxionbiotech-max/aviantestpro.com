    Sample Collection Quick-Reference Card¶

    Feather Collection (DNA Sexing)¶

    ┌─────────────────────────────────────────────┐
│           FEATHER COLLECTION                 │
├─────────────────────────────────────────────┤
│  ☑ Use freshly plucked feathers ONLY        │
│  ☑ 3–5 feathers per bird                    │
│  ☑ Small birds: 5–7 feathers                │
│  ☑ Pluck from chest or flank                │
│  ☑ Check: follicle bulb visible at base     │
│  ☑ Store in paper envelope (NOT plastic)    │
│  ☑ Label each envelope with bird ID         │
│  ☑ Room temperature storage                 │
│  ☑ Ship within 4 weeks of collection        │
└─────────────────────────────────────────────┘

    Swab Collection (Disease Testing)¶

    ┌─────────────────────────────────────────────┐
│           SWAB COLLECTION                    │
├─────────────────────────────────────────────┤
│  ORAL SWAB:                                  │
│  ☑ Insert into oropharynx + choanal slit    │
│  ☑ Rotate 5–10 seconds                      │
│  ☑ Place into stabilization solution        │
│                                              │
│  CLOACAL SWAB:                               │
│  ☑ Insert 0.5–1 cm into cloaca              │
│  ☑ Rotate 3–5 seconds                       │
│  ☑ Place into stabilization solution        │
│                                              │
│  ☑ Seal tube tightly                        │
│  ☑ Label with bird ID + date                │
│  ☑ Store at 2–8°C → ship with cold pack     │
└─────────────────────────────────────────────┘

    Blood Collection (FTA Card / Filter Paper)¶

    ┌─────────────────────────────────────────────┐
│           BLOOD COLLECTION                   │
├─────────────────────────────────────────────┤
│  FTA CARD:                                   │
│  ☑ Apply 1–2 drops blood to card            │
│  ☑ Allow to air-dry 30 min (no direct sun)  │
│  ☑ Store in sealed bag with desiccant       │
│  ☑ Room temperature storage (years)         │
│                                              │
│  FILTER PAPER (DBS):                         │
│  ☑ Apply 3–4 drops blood to card            │
│  ☑ Air-dry completely (> 1 h)               │
│  ☑ Store individually in paper envelopes    │
│  ☑ Room temperature or refrigerated         │
└─────────────────────────────────────────────┘

    Common Errors & Prevention¶

    ErrorConsequencePrevention
    Using molted feathersNo DNA (no follicle)Always pluck fresh feathers
    Plastic bag for feathersCondensation → mold → DNA degradationAlways use paper envelope
    Missing bird ID on sampleSample cannot be processedLabel each envelope before collection
    Swab tube leakageBiohazard risk + sample lossDouble-check cap seal; use secondary container
    Storage in direct sunlightUV damage → DNA degradationStore in opaque container or dark location
    Over-drying blood spotDNA may fragmentFollow drying time: 30–60 min, not > 2 h
